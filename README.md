# 📘 Student Score Prediction using Machine Learning (Linear Regression)

## 🎯 Overview
This project presents a data-driven approach for predicting **student exam scores** based on study-related features such as **hours studied**. The project applies **Simple Linear Regression** to model the relationship between input variables and performance outcomes.

By leveraging structured educational data, this project demonstrates how machine learning can be used to analyze learning patterns, forecast academic performance, and support academic planning through predictive analytics.

---

## 🎯 Objectives
- Conduct Exploratory Data Analysis (EDA) to understand relationships between study time and exam performance.
- Develop and train a **Linear Regression** model to predict continuous score values.
- Visualize data distributions and regression trends for interpretability.
- Evaluate model performance using **R² Score** and **Mean Absolute Error (MAE)**.

---

## 🧩 Methodology

### Data Preprocessing
- Cleaned and validated dataset for missing and inconsistent values.
- Handled outliers to improve model stability.
- Prepared feature and target variables for model training.

### Exploratory Data Analysis (EDA)
- Analyzed statistical summaries and data distributions.
- Visualized relationships between hours studied and scores using scatter plots.
- Identified linear trends and data correlations.

### Model Development
- Implemented **Simple Linear Regression** using Scikit-learn.
- Trained the model on historical student performance data.
- Generated best-fit regression line to represent prediction behavior.

### Model Evaluation
- Measured model performance using:
  - R² Score
  - Mean Absolute Error (MAE)
- Compared predicted scores against actual scores to validate model accuracy.

---

## 🧠 Tools and Technologies

**Programming Language:** Python

**Libraries & Frameworks:**
- Data Handling: Pandas, NumPy

## 📈 Results and Insights
- The Linear Regression model successfully captured the relationship between study hours and exam scores.
- The model achieved strong predictive performance as indicated by R² Score.
- Visualization of the regression line confirmed a clear positive correlation between study time and performance.
